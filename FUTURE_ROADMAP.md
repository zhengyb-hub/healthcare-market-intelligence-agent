# Future Roadmap

Phase 6 intentionally follows `POLISH > EXPAND`. The items below are documented ideas, not implemented or promised capabilities.

## Near-term portfolio maintenance

- Add approved static portfolio screenshots after capture in an unrestricted local browser.
- Add accessibility review with keyboard-only navigation and a screen reader.
- Add visual regression snapshots for the nine primary workspaces.
- Pin dependency ranges after a clean Python 3.12 installation test.
- Add a release changelog and signed tag when the repository is published.

## Evidence operations

- Scheduled source refresh with explicit source ownership and robots/terms review
- Configurable Evidence retention and freshness policies
- Reviewer-assisted duplicate merge decisions
- Additional import adapters for approved internal source formats
- Source-health monitoring and broken-link reporting

## Enterprise workflow

- Authentication and role-based access control
- Managed secrets and environment-specific configuration
- Multi-user review assignment and service-level targets
- Notification integrations for approved collaboration tools
- Managed relational database, backups, and disaster recovery
- Observability, audit retention, and operational alerting

## Intelligence expansion

- Approved prompt/version registry and offline model evaluation
- Multilingual Evidence normalization with source-language preservation
- Configurable healthcare taxonomy variants by market
- Reviewer-calibrated Claim quality sampling
- Longitudinal change analysis after sufficient dated Evidence exists

## Measurement

- Complete at least five real paired Manual/AI-assisted Benchmark tasks
- Pre-register comparability and reviewer rules before data collection
- Report medians, distributions, sample size, exclusions, and uncertainty
- Validate usefulness and decision quality in addition to speed

## Explicitly out of scope for the current release

- CRM
- automated email or messaging
- unrestricted full-web crawling
- predictive market-share modeling
- production healthcare-client integrations
- sensitive patient or private hospital data
